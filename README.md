## 🚀 How to Push to GitHub & Launch GitHub Pages (2 Minutes)

Follow these simple steps in your terminal or Command Prompt to push this portfolio to your GitHub account (`satyamgarg132008-cyber`) and host it for free on **GitHub Pages**:

### Step 1: Open Terminal in the Portfolio Folder
In PowerShell or Git Bash, navigate to this project folder:
```bash
cd "C:\Users\satyam\.gemini\antigravity\scratch\satyam-portfolio"
```

### Step 2: Initialize Git & Commit Updates
```bash
# Stage all files (including new assets and certificate images)
git add .

# Commit changes
git commit -m "feat: add verified Microsoft Azure & Thiranex certificates with interactive modal"

# Rename branch to main
git branch -M main
```

### Step 3: Link to Your GitHub Account
Create a repository on GitHub (e.g. `https://github.com/satyamgarg132008-cyber/portfolio` or `satyamgarg132008-cyber.github.io`), then run:

```bash
# Link to your remote GitHub repository
git remote add origin https://github.com/satyamgarg132008-cyber/portfolio.git

# Push code to GitHub
git push -u origin main
```

*(Note: Replace `portfolio.git` with your exact repository name if different).*

### Step 4: Turn on GitHub Pages (Instant Free Hosting!)
1. Go to your repository on GitHub: `https://github.com/satyamgarg132008-cyber/portfolio`
2. Click **Settings** (top right tab)
3. On the left sidebar, click **Pages**
4. Under **Build and deployment > Branch**, select `main` and `/ (root)`
5. Click **Save**
6. Within 1 minute, your portfolio will be live at:
   `https://satyamgarg132008-cyber.github.io/portfolio/`

## 💻 How to Preview Locally

You do not need to install anything!
Simply **double click `index.html`** in File Explorer to open it in Chrome, Edge, or Firefox.

Alternatively, if you use VS Code:
- Right click `index.html` -> **Open with Live Server**

Or run Python's built-in local server:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.
